# SpotDeal

**SpotDeal** helps students find nearby restaurants offering exclusive food deals. Browse by map, filter by cuisine or dietary needs, and get notified when your favorite spots drop new offers.

👉 [Live Project on Lovable](https://spot-deal-social.lovable.app/)

## Tech Stack

- React + TypeScript
- Tailwind CSS
- shadcn/ui
- Vite

## Local Setup

```bash
git clone <your_repo_url>
cd spotdeal
npm install
npm run dev
